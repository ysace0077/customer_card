# 고객 상담 카드 관리 시스템

깔끔하고 효율적인 고객 상담 카드 관리를 위한 웹 애플리케이션입니다.

## 🌟 주요 기능

### 📤 상담 카드 업로드
- 판매자, 고객명, 상담 날짜 입력
- JPG 이미지 파일 업로드 (모바일 카메라 지원)
- 메모 추가 기능
- GitHub 자동 백업

### 🔍 스마트 검색 & 필터링
- 고객명 실시간 검색
- 판매자별 필터링
- 기간별 필터링 (금주, 당월, 지난 달)
- 직관적인 버튼 인터페이스

### 🔄 클라우드 동기화
- GitHub 저장소 연동
- 자동 데이터 백업
- 다중 기기 동기화
- 오프라인 지원

### 📱 모바일 최적화
- 반응형 디자인
- 터치 친화적 인터페이스
- 모바일 카메라 직접 촬영
- PWA 지원

## 🚀 시작하기

### 1. GitHub 저장소 설정
1. GitHub에서 새 저장소 생성
2. Settings → Developer settings → Personal access tokens
3. "Contents" 권한이 있는 토큰 생성
4. 앱에서 ⚙️ 설정 버튼 클릭하여 정보 입력

### 2. 기본 사용법
1. **업로드**: 상담 카드 정보와 이미지 업로드
2. **검색**: 고객명으로 검색하거나 필터 사용
3. **동기화**: 🔄 버튼으로 다른 기기와 동기화

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: localStorage + GitHub API
- **Design**: 모바일 퍼스트 반응형 디자인
- **Icons**: 이모지 기반 직관적 UI

## 🆘 문제 해결

### 동기화 문제
1. GitHub 설정 확인
2. 인터넷 연결 확인
3. 토큰 권한 확인
4. 🔄 동기화 버튼 클릭

### 이미지 업로드 실패
1. JPG 파일 형식 확인
2. 파일 크기 10MB 이하 확인
3. GitHub 저장소 용량 확인

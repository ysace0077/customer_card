# 고객 상담 카드 관리 시스템 v2.0

GitHub를 데이터베이스로 직접 사용하는 클라우드 네이티브 상담 카드 관리 시스템입니다.

## 🚀 새로운 아키텍처

### 📊 GitHub 직접 연동 방식
- **브라우저 저장소 미사용**: localStorage 의존성 완전 제거
- **GitHub 직접 저장**: 모든 데이터가 GitHub에 실시간 저장
- **클라우드 네이티브**: 브라우저 간 완벽한 데이터 일관성
- **실시간 동기화**: 업로드/삭제 시 즉시 GitHub 반영

### 🔄 데이터 플로우
```
업로드 → GitHub 이미지 저장 → GitHub 데이터 저장 → 완료
검색 → GitHub에서 실시간 로드 → 화면 표시
동기화 → GitHub에서 최신 데이터 로드 → 화면 갱신
삭제 → GitHub에서 데이터 삭제 → 화면 갱신
```

## 🌟 주요 특징

### 📤 실시간 업로드
- GitHub에 이미지와 데이터 동시 저장
- 업로드 즉시 다른 기기에서 확인 가능
- 브라우저 캐시 없이 순수 클라우드 저장

### 🔍 실시간 검색
- 검색 탭 진입 시 GitHub에서 최신 데이터 로드
- 캐시 무시로 항상 최신 상태 보장
- 다중 기기 간 완벽한 데이터 동기화

### 🗑️ 실시간 삭제
- GitHub에서 데이터 즉시 삭제
- 다른 기기에서 동기화 시 즉시 반영
- 완전한 데이터 일관성 보장

## 🛠️ 기술 아키텍처

### 데이터 저장 구조
```
GitHub Repository/
├── data/
│   └── consultation_cards.json    # 모든 카드 메타데이터
├── images/
│   ├── 20241220_이호만점장_김고객_1234567890.jpg
│   ├── 20241220_김승진실장_박고객_1234567891.jpg
│   └── ...
└── README.md
```

### API 사용 패턴
- **GitHub Contents API**: 파일 CRUD 작업
- **캐시 무시**: 모든 요청에 타임스탬프 추가
- **원자적 업데이트**: SHA 기반 안전한 업데이트
- **에러 핸들링**: 네트워크 오류 시 명확한 피드백

## 🚀 시작하기

### 1. GitHub 저장소 준비
```bash
# 1. GitHub에서 새 저장소 생성
# 2. Settings → Pages → Source: GitHub Actions 설정
# 3. Settings → Developer settings → Personal access tokens
# 4. "Contents" 권한이 있는 토큰 생성
```

### 2. 앱 설정
1. ⚙️ 설정 버튼 클릭
2. GitHub 정보 입력:
   - 사용자명/조직명
   - 저장소명
   - Personal Access Token
   - 브랜치명 (기본: main)
3. 🔗 연결 테스트 실행
4. 💾 설정 저장

### 3. 사용 시작
- **업로드**: 즉시 GitHub에 저장
- **검색**: 실시간 GitHub 데이터 조회
- **동기화**: 🔄 버튼으로 최신 데이터 로드

## 🔒 보안 및 성능

### 보안
- Personal Access Token 사용
- 프라이빗 저장소 지원
- 클라이언트 사이드 암호화 가능
- 토큰은 브라우저에만 저장

### 성능
- 캐시 무시로 데이터 일관성 보장
- 이미지 최적화 (최대 10MB)
- 비동기 처리로 UI 블로킹 방지
- 에러 시 명확한 피드백

## 📱 지원 환경

- **브라우저**: Chrome, Safari, Firefox, Edge
- **모바일**: iOS Safari, Android Chrome
- **네트워크**: 온라인 전용 (GitHub API 필요)
- **저장소**: GitHub 퍼블릭/프라이빗 모두 지원

## 🆘 문제 해결

### GitHub 연결 실패
1. 토큰 권한 확인 (Contents 권한 필요)
2. 저장소 접근 권한 확인
3. 네트워크 연결 상태 확인

### 데이터 동기화 문제
1. 🔄 동기화 버튼 클릭
2. 브라우저 새로고침
3. GitHub 저장소 직접 확인

### 업로드 실패
1. 파일 형식 확인 (JPG만 지원)
2. 파일 크기 확인 (10MB 이하)
3. GitHub 저장소 용량 확인
